# Detective Attention — утверждённая сборка

В этой версии нет папки assets.

Страницы:
- index.html — главная
- catalog.html — каталог
- case-01.html … case-06.html — шесть дел
- how.html — «Как это работает?»
- final.html — финал

Изображения каждого утверждённого экрана встроены прямо в соответствующий HTML.
В корне лежат только два аудиофайла: detective-history-2.mp3 и clock-tick.wav.

Интерактивность:
- карточки каталога открывают отдельные страницы дел;
- стрелка «назад» возвращает в каталог;
- меню ведёт в каталог, инструкцию и финал;
- четыре кнопки времени открывают Telegram @vshooroop с готовым сообщением;
- финальная кнопка возвращает к каталогу;
- музыка запускается автоматически, если браузер разрешает, иначе после первого касания.

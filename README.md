# Detective Attention

Одностраничный сайт-финал детективного квеста в стиле Шерлока Холмса.

## Файлы
- `index.html`
- `styles.css`
- `script.js`

## Как запустить
Просто откройте `index.html` в браузере.

## GitHub Pages
1. Загрузите эти файлы в корень репозитория.
2. Откройте `Settings` → `Pages`.
3. В `Build and deployment` выберите `Deploy from a branch`.
4. Выберите ветку `main` и папку `/ (root)`.
5. Нажмите `Save`.

Через некоторое время GitHub покажет публичную ссылку сайта.
